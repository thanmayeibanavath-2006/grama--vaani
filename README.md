# Grama Vaani — recreated front-end

This is a responsive, static front-end recreation based on the screenshots provided.

## Run it
- Extract the ZIP.
- Open `index.html` in a browser, or use VS Code Live Server.
- No npm installation is required.

## Publish a new website
You can deploy this folder to a static hosting service such as Vercel by importing it as a project or uploading it using a supported deployment workflow. The website owner must create/sign in to their own hosting account and complete deployment.

## Important demo limitations
- Grievance records are stored in the current browser's `localStorage` only. They do not sync between phones or computers.
- Panchayat login is a visual demo; there is no secure authentication.
- Feedback is a front-end demonstration and is not sent to a server.
- To make this a real public grievance system, add a backend/database, secure authentication, server-side validation, and appropriate privacy/security protections.
- The VVIT circle in the header is a text-style placeholder, not an official institutional logo.
